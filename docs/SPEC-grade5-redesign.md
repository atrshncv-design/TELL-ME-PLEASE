# SPEC: Ревизия 5 класса + геймификация + редизайн

_Спецификация сгенерирована после grilling (15 решений). Применяется к 5 классу (контент/To Be) + всем 5 классам (UX-фундамент)._

## Состояние на старте

- 5 классов × 16 заданий = 80 заданий (5-9 классы) на main (`33ba66f`)
- Голос, аналитика, прогресс (localStorage), цветовая кодировка — работают
- Фото маскота Verb Bot в `assets/mascot/verb-bot-original.jpg`
- Обновлённый документ 5 класса в `/tmp/grade5_new.txt` (новый контент + правки)

## Problem Statement

Клиентка прислала обновлённый документ по 5 классу с правками к существующим механикам + новый контент + концепция маскота Verb Bot как «навигатора по карте глаголов». Нужна ревизия 5 класса под методические правки + большой редизайн под геймификацию (карта-миры, маскот, очки, звуки) для всех классов.

## Solution

8 блоков по принципу «быстрые победы → сложное»: контент-обновление → UX-правки → новые механики (ClozeTextTask) → To Be вкладка → полезные ссылки → маскот → карта-миры → геймификация. После каждого блока коммит + пуш + проверка.

## User Stories

### Контент и механики
1. Как ученик, я хочу видеть обновлённый контент заданий 5 класса (новые глаголы, предложения, шутки), чтобы материал соответствовал актуальной методичке.
2. Как ученик, я хочу в «Выбери правильную форму» (бывш. «Шутка») понятное название без слова «шутка».
3. Как ученик, я хочу вернуться к предыдущему вопросу кнопкой «Назад» (просмотр моего ответа), чтобы проверить себя.
4. Как ученик, я хочу в Гарри Поттере / Wh-вопросах / Наречиях единую механику: клик по пропуску → клик по слову из банка.
5. Как ученик, я хочу новую вкладку «Глагол to be» с 5 заданиями (Сборка, Магнит, Почемучка, Детектор лжи, Письмо).
6. Как ученик, я хочу раздел «Полезное» со ссылками на песенки для самостоятельного изучения.

### Геймификация и UX
7. Как ученик, я хочу видеть Verb Bot — дружелюбного робота, который меня подбадривает репликами («Great job!», «Try again!»).
8. Как ученик, я хочу карту-путь: вертикальная тропа с островками-заданиями, где Verb Bot ведёт меня вперёд.
9. Как ученик, я хочу, чтобы карта была разбита на «миры» по категориям (Грамматика/To Be/Словарь/Аудирование/Общение), каждый со своим цветом.
10. Как ученик, я хочу получать звёзды (⭐) за задания, бейджи 💎 за идеал, и слышать звуки на правильный/неправильный ответ.

## Implementation Decisions

### Блок 1: Контент-обновление JSON 5 класса (делегировать субагенту)
- Пройти по обновлённому документу (`/tmp/grade5_new.txt`) и обновить ВСЕ JSON 5 класса новым контентом: глаголы для окончаний, шутки (теперь «Выбери форму»), отрицания, Do/Does, Wh-вопросы, лесенка, вставь форму, наречия, Гарри Поттер-рассказ, Гарри Поттер-интервью, расскажи о себе, поговори со сверстником.
- Рулетка (`grammar_roulette`) — ОТЛОЖЕНА (ждём слово-банк от клиентки). Контент не обновлять, оставить как есть.
- Синхронизировать content/grade_5/ и frontend/public/content/grade_5/.

### Блок 2: Переименование + кнопка «Назад»
- `grammar_joke_quiz.json` → title «Выбери правильную форму» (везде: JSON + index.json).
- Кнопка «← Назад» в QuizTask и FillInTask: возвращает к предыдущему вопросу, показывает данный ответ (зелёным/красным), БЕЗ возможности изменить. Балл не пересчитывается.

### Блок 3: ClozeTextTask (новый компонент)
- Механика: двухкликовая (клик по пропуску → клик по слову). Клик по заполненному → возврат в банк.
- JSON-формат: `{text_with_blanks: "...___...___...", word_bank: [...], answers: [[варианты для пропуска 1], ...]}`.
- Подключить: Гарри Поттер-рассказ (единый текст), Wh-вопросы (2 пропуска), Наречия-построй (наречие ЛИБО время).
- Подлежащее и сказуемое подчёркнуты (где применимо).

### Блок 4: Вкладка «Глагол to be» (5 новых заданий)
- Новая категория `to-be` (бирюзовый цвет).
- 5 заданий из документа 5 класса:
  1. `tobe_assembly` (Сборка) — fill-in am/is/are
  2. `tobe_magnet` (Магнит) — утверждение → отрицание (not)
  3. `tobe_why` (Почемучка) — утверждение → вопрос (инверсия)
  4. `tobe_lie_detector` (Детектор лжи) — найти и исправить ошибку
  5. `tobe_email` (Письмо) — cloze текст с am/is/are
- index.json: добавить `to-be` категорию.

### Блок 5: Раздел «Полезное»
- Новая секция «📚 Полезное» на sections-странице (5-я).
- JSON `content/tasks/grade_5/links.json`: массив `{title, url, description}`.
- Заглушки-плейсхолдеры (клиентка заполнит).

### Блок 6: Verb Bot (маскот)
- Floating-компонент в углу (60-80px), на всех экранах.
- Облачко с репликами при событиях: старт задания («Let's go!»), правильно («Great job!»), ошибка («Try again!»), финал («Ready for the next level?»), приветствие на главной («Hi! I'm Verb Bot!»).
- 1 фото сейчас (`verb-bot-original.jpg`) для всех реплик. Архитектура: папка `assets/mascot/{happy,think,cheer,sad}.jpg` → сейчас 4 копии одного файла. Замена тривиальна.

### Блок 7: Карта-миры (главный редизайн)
- Заменить текущую плоскую sections-страницу на карту-путь.
- 5 миров-зон по категориям: grammar (индиго), to-be (бирюзовый), vocabulary (изумруд), listening (янтарь), speaking (розовый).
- Каждый мир — вертикальная тропа с островками-заданиями (4-5 шт).
- Между мирами — переход + приветствие Verb Bot.
- Сверху — мини-навигация по мирам.
- Прогресс визуализирован: пройденное затемнено с галочкой, Verb Bot на текущем.
- Mobile-first (вертикальный скролл).

### Блок 8: Геймификация
- Звёзды (⭐): за задание = балл (8/10 = 8 звёзд). Сумма в шапке карты (localStorage).
- Бейджи 💎: за 100% в задании, на острове.
- Звуки: короткие эффекты на правильный/неправильный/финал. Unlock AudioContext на первом клике (autoplay policy).
- НЕ: разблокировка следующих заданий, streak.

## Cross-class scope (Q15a)
- UX-фундамент (карта-миры, маскот, геймификация, кнопка «Назад», переименование) — на ВСЕ 5 классов.
- Контент-обновления JSON, ClozeTextTask для Гарри/Wh/Наречий, To Be вкладка — ТОЛЬКО 5 класс (контент-методичек по 6-9 пока нет).

## Out of Scope

- Реальные ссылки в «Полезном» (клиентка заполнит)
- 6-9 классы — контент-правки и To Be (нет методичек)
