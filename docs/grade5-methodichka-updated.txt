1 . Окончания ( распределить по  трем столбикам из таблицы)
•  Обычные глаголы с окончанием -s (Present Simple, he/she/it): like, live, learn, help, read
•  Глаголы с окончанием -es (шипящие/свистящие и на -o): pass, wash, watch, go, do
•  Глаголы с y → ies (перед y стоит согласная): study, carry, try, cry, tidy
•  Глаголы с y после гласной (окончание не меняется, просто -s): play, enjoy, stay, buy, say



2. Окончания (викторина- выбрать из двух предложенных вариантов)
1) Обычные с окончанием -s
Форма he/she/it: добавляем -s.
want → wants
open → opens
visit → visits
jump → jumps
dance → dances
2) Обычные с окончанием -es (шипящие/свистящие и -o)
Форма he/she/it: добавляем -es.
pass → passes
watch → watches
fix → fixes
miss → misses
go → goes
(Если хотите ровно 5 в группе -es, можно убрать один, например miss или fix.)
3) Глаголы с y → ies (перед y согласная)
Форма he/she/it: y меняется на ies.
fly → flies
copy → copies
hurry → hurries
try-tries
4)  y после гласной (окончание не меняется)
Форма he/she/it: просто -s, y остаётся.
play → plays
enjoy → enjoys
stay → stays
buy → buys
say → says
