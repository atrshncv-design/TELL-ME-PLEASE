## Контекст

- Репозиторий: https://github.com/atrshncv-design/TELL-ME-PLEASE

## Шаги

1. Склонируй репозиторий В НЕЗАВИСИМЫЙ каталог (например, `/tmp/tmp-deploy`), НЕ внутрь каталога платформенного проекта. Переключись на `main`, подтяни `origin/main`, проверь `3b6041b` в истории.
2. Адаптируй файлы из ТЕКУЩЕЙ сборки на сервере (bash-скрипты, prisma, конфиги).
3. `cd frontend && npm ci` (postinstall удалён). ВАЖНО: `npm ci` выполнять только в `frontend/` — там лежит `package-lock.json`. В корне платформенного проекта для обёртки допустим `bun install`.
4. Выставь переменные окружения: `LLM_API_KEYS` (обязательно), `ADMIN_LOGIN`, `ADMIN_PASSWORD`.
5. `npm run build`. Сборка создаёт `.next/standalone/` — именно её деплой.
6. Если платформа требует тарболл — собери через `BUILD_ID=<id> bash .zscripts/build.sh` и ПРОВЕРЬ РАЗМЕР: `du -m /tmp/build_fullstack_<id>.tar.gz` — строго < 50MB. Опубликуй `.next/standalone/`.
7. Дымовой тест (перед ним: `lsof -i :3000` должен быть ПУСТ — если порт держит старый процесс, убить его `kill -9`; после старта сервера взять из отданного HTML первый чанк `/_next/static/chunks/*.js` и проверить curl'ом — должен быть 200):
   - `/` — лендинг (H1 «TIME TRAVEL MISSION» заглавными)
   - `/mission` — 12 эпох + карточка экзамена; чип называется «Обучение 🎓» (не «Инструктаж»)
   - страница любой эпохи — над бейджами A1/A2/B1/B2 есть слово Level
   - `/epoch/present-simple/a1/station-1` — «Проверка Системы»: 26 вопросов, №24 ответ «have»
   - `/epoch/present-simple/a1/station-4` — называется «Интервью с Гарри Поттером»
   - `/epoch/past-simple/a1/station-0` — первая станция «Тренажёр Неправильных Глаголов» ОТКРЫВАЕТСЯ
   - `/epoch/past-simple/a2/station-3` — называется «Викторина Времен»
   - `/epoch/present-perfect/b2/station-2` — «Ловушки со Статичными Глаголами (For/Since)»
   - `/epoch/future-perfect/b1/station-3`, `/exam` — в текстах нет слова «стативные»
   - `/epoch/present-perfect/a1/station-7` — на экране результата есть кнопка «Дальше →»
   - `/epoch/present-perfect-continuous/a2/station-8` — «Новенький в классе (Промпт)»: контент промпта + диалог, НЕ заглушка
   - `/epoch/present-continuous/a1/station-5` — «Рефлекс Ответа»: у вопроса про teacher два РАЗНЫХ варианта
   - **Мобайл (<640px)**: Verb Bot компактный (фото ~48px, пузырь ~150px), не закрывает пол-экрана
   - **Маскот**: персонаж версии 18.08 (файлы 1208×1302) на странице эпохи и в инструктаже
   - `/music`, `/exam` — открываются
   - **TTS (healthcheck)**: `curl "<URL>/api/tts?text=Hello&voice=en-GB-SoniaNeural"` → 200, audio/mpeg. Если 503 — оба провайдера недоступны, проверить сеть сервера (edge-tts → фолбэк translate_tts)
   - Голосовые: бот отвечает на текст
