Ты — агент платформы space.z-ai. Твоя задача — выкатить новую версию веб-приложения на Next.js по инструкции ниже. Работай в терминале, следуй шагам строго по порядку. Ничего не пропускай и не меняй без необходимости. Русский язык — рабочий.

## Контекст

- Репозиторий: https://github.com/atrshncv-design/TELL-ME-PLEASE
- Ветка: `main`. Приложение — Next.js (App Router) в подпапке `frontend/`.
- Платформа space.z-ai: Next.js-only, без Python/Docker. Node 22.15.0+ (nvm use 22).
- HEAD-коммит для деплоя: **`9fa5dbe`** — fix(ui): новый маскот + форматирование примеров в инструктажах. Кодовый контент: `a8fc9db` (правки клиентки, 9 тикетов).

### Что нового в этой версии

- **Новый маскот**: все 5 файлов (`happy.jpg`, `cheer.jpg`, `sad.jpg`, `think.jpg`, `instruct.jpg`) в `frontend/public/mascot/` заменены на новый рисованный персонаж.
- **Форматирование инструктажей**: примеры в theory-слайдах автоматически выделяются отдельным блоком (фон amber-50, курсив, по центру). Парсинг по паттерну: заглавная буква + точка/?/! + скобки с переводом.
- **Standalone build**: `output: 'standalone'` в next.config — `next build` создаёт `.next/standalone/` (~44MB) с минимальными зависимостями.
- **Удалён postinstall**: `npm ci` больше не запускает build автоматически.
- **Правки клиента**: cloze починены, ключи FC исправлены, инструктажи разбиты на короткие слайды, 5 новых prompt-card станций, sunoPrompt на английском.

## Шаги

1. Склонируй репозиторий, переключись на `main`, подтяни `origin/main`, проверь `9fa5dbe` в истории.
2. Адаптируй файлы из ТЕКУЩЕЙ сборки на сервере (bash-скрипты, prisma, конфиги).
3. `cd frontend && npm ci` (postinstall удалён — `--ignore-scripts` не нужен).
4. Выставь переменные окружения: `LLM_API_KEYS` (обязательно), `ADMIN_LOGIN`, `ADMIN_PASSWORD`.
5. `npm run build`. Сборка создаёт `.next/standalone/` — именно её деплой.
6. Проверь build id. Опубликуй `.next/standalone/` на новом subdomain.
7. Дымовой тест:
   - `/` — лендинг (H1 «Time travel mission»)
   - `/mission` — 12 эпох + карточка экзамена
   - `/epoch/present-perfect/a1/station-6` — cloze «Письмо из Отпуска» (раньше падал)
   - `/epoch/future-continuous/a2/station-5` — blank3 принимает «will be eating»
   - `/epoch/present-perfect-continuous/a2/station-8` — НОВАЯ prompt-card «Новенький в классе»
   - `/epoch/future-simple/a2/station-8` — НОВАЯ prompt-card «Планы на компьютер»
   - `/music` — промпты Suno на английском
   - `/exam` — пролог + сектора
   - **Маскот**: на странице эпохи и в инструктаже — новый рисованный персонаж (не старый фотореалистичный)
   - **Инструктаж**: открыть «Смотреть инструктаж» — примеры выделены отдельным блоком (amber-50 фон, курсив, по центру)
   - TTS: `curl "<URL>/api/tts?text=Hello&voice=en-GB-SoniaNeural"` → 200, audio/mpeg
   - Голосовые: бот отвечает на текст
