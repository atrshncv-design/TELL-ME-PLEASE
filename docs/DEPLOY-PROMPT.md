## КРИТИЧЕСКИЕ ПРАВИЛА (из ошибок прошлых разов — НЕ НАРУШАЙ)

1. **Используй ТОЛЬКО штатный инструмент деплоя платформы.** НЕ копируй файлы вручную,
   НЕ правь файлы на сервере напрямую — платформа разворачивает проект из `repo.tar` при
   старте контейнера, ручные правки наружу не пробрасываются.
2. **НЕ запускай сервер вручную** (`bun run dev`, `next dev`, `next start` и т.п.) — штатный
   процесс запускается при старте контейнера. Ручной сервер конфликтует и не обслуживает
   внешний трафик.
3. **НЕ создавай временных эндпоинтов** (типа `/api/debug-env`) и НЕ добавляй ничего в
   репозиторий сверх того, что в нём есть. Env проверяй косвенно через `/api/chat/stream`.
4. **Платформа кэширует старый билд на уровне ингресса.** Если после деплоя внешний URL
   отдаёт старую версию — это НЕ чинится ручными правками. Остановись и сообщи пользователю:
   нужно нажать «Restart/Redeploy» в дашборде.
5. **`next dev` (Turbopack) нестабилен на этой платформе** (падает после 1–3 запросов) —
   это известная проблема, не чини её. В репозитории уже настроен production-режим:
   `"dev": "next start -p 3000"` + `"postinstall": "next build"` — этого достаточно, ничего
   не переписывай.
6. **Ключи/пароли — НИКОГДА не выводи в отчёт и не проси у пользователя в чате.** В дашборде
   уже должны быть залиты переменные из `frontend/.env.example`. Если какой-то переменной
   нет — просто скажи пользователю, КАКАЯ отсутствует, а не проси прислать значение.
7. **Если install шёл через bun** — проверь, что `.next/` появился (bun по умолчанию БЛОКИРУЕТ
   postinstall: «Blocked 1 postinstall»). Если `.next/` нет — значит `next build` не выполнился:
   выполни `npm run build` явно (или `bun pm untrusted` и переустанови), затем передеплой.
   Без `.next/` сервер падает — это главный кандидат на «тихий» провал деплоя.
8. **Материалы заказчицы в репо НЕ добавляй и не трогай** — они в `.gitignore`
   (`АНГЛ КОНТЕКСТ.md`, `Задания АНГЛ/`, `НОВЫЕ МАТЕРИАЛЫ*/`): если увидишь их в рабочей
   копии — это локальные файлы пользователя, не часть проекта.
