### Почему прошлые деплои падали (не повторяй)

1. **Тарболл без чанков**: `.zscripts/build.sh` копировал статику из `standalone/.next/static`, которой там не бывает → 6MB-тарболлы без JS/CSS → белый экран. **ИСПРАВЛЕНО в `691a0c6`** — теперь скрипт громко падает, если чанков нет.
2. **Рабочий каталог платформы `/home/z/my-project` сбрасывается до шаблона z.ai** (nextjs_tailwind_shadcn_ts) между сессиями. Шаблонный `bun.lock`, `examples/websocket`, `db:push` ломали сборку нашего приложения.
3. **Песочница убивает процессы через секунды** — не пытайся «держать сервер» ради превью. Только атомарные проверки: старт → curl → kill.
4. **Голый HTTP 200 ничего не доказывает**: проверь, КТО отвечает (порт мог занять другой процесс — был случай EADDRINUSE от чужого dev-сервера). Всегда: `lsof -i :PORT` пуст ДО старта; после старта curl конкретного чанка из отданного HTML.

### Что нового в этой версии (добавка к списку ниже)

- **Починен краш 500 на ВСЕХ страницах станций эпох** `/epoch/<slug>/<sector>/<stationId>` — клиентский контекст случайно рендерился серверным компонентом. Это критично: без этого фикса основной флоу заданий мёртв.
- **Verb Bot отвечает**: клик по аватару открывает окно голосового чата с ботом (STT → LLM → TTS), персона «дружелюбный репетитор».
- **Мобильные**: контент больше не заезжает под флоат-бота (резерв места), пузырь речи прячется при скролле.
- **Выключатель звука глушит и речь** (раньше только эффекты): центральный гейт в обоих TTS-каналах, немедленный stop.
- **Неверный ответ однозначен**: выбор сразу крупный красный с ✗, пауза ~1.8 c до перехода, правильный ответ — скромной строкой без праздничной галочки (QuizTask).
- **Шапка станции**: длинные названия больше не ломают кнопку «← Назад».
- **Обучение эпохи**: глобальный тумблер звука скрыт при открытой модалке, в шапке модалки свой компактный тумблер рядом с «✕».

3. Из корня клона: `BUILD_ID=ttm21 bash .zscripts/build.sh` → тарболл `/tmp/build_fullstack_ttm21.tar.gz`.
4. Проверь тарболл ЖЁСТКО:
   - размер < 50MB;
   - `tar -tzf … | grep -c "static/chunks/.*\.js$"` → ≥ 20;
   - присутствуют: `start.sh`, `Caddyfile`, `next-service-dist/server.js`, `next-service-dist/public/mascot/happy.jpg`;
   - если хоть что-то не так — СТОП, доложи, не публикуй.
5. Атомарный прогон: распакуй в `/tmp/ttm-art`, `lsof -i :3311` (пусто?), затем `cd /tmp/ttm-art/next-service-dist && PORT=3311 HOSTNAME=127.0.0.1 node server.js &`, подожди 5 сек:
   - `curl localhost:3311/` → 200 и в HTML есть «Обучение»;
   - возьми первый чанк из HTML → curl → 200;
