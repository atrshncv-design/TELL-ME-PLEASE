## Шаги

1. Склонируй репозиторий В НЕЗАВИСИМЫЙ каталог (например, `/tmp/tmp-deploy`), НЕ внутрь каталога платформенного проекта — иначе клон попадёт в сборку (это и раздувало прошлый тарболл). Переключись на `main`, подтяни `origin/main`, проверь `0b62f3b` в истории.
2. Адаптируй файлы из ТЕКУЩЕЙ сборки на сервере (bash-скрипты, prisma, конфиги).
3. `cd frontend && npm ci` (postinstall удалён — `--ignore-scripts` не нужен). ВАЖНО: `npm ci` выполнять только в `frontend/` — там лежит `package-lock.json`. В корне платформенного проекта лежит `bun.lock`, там `npm ci` падает с EUSAGE (для платформенной обёртки допустим `bun install`).
4. Выставь переменные окружения: `LLM_API_KEYS` (обязательно), `ADMIN_LOGIN`, `ADMIN_PASSWORD`.
5. `npm run build`. Сборка создаёт `.next/standalone/` — именно её деплой.
6. Проверь build id. Если платформа требует тарболл — собери через `BUILD_ID=<id> bash .zscripts/build.sh` и ПРОВЕРЬ РАЗМЕР: `du -m /tmp/build_fullstack_<id>.tar.gz` — строго < 50MB (если больше — tar -tzf и найди, что лишнее, доложи). Опубликуй `.next/standalone/` на новом subdomain.
7. Дымовой тест:
   - `/` — лендинг (H1 «Time travel mission»)
   - `/mission` — 12 эпох + карточка экзамена
   - `/epoch/past-perfect/a2/station-3` — «Дебаггинг» ОТКРЫВАЕТСЯ (раньше — белая страница)
   - `/epoch/future-perfect/a2/station-6` — «Блог: Мои Планы»: микрофон продолжает слушать после первой фразы (не требует повторного нажатия)
   - `/epoch/past-perfect-continuous/a1/station-7` — «Интервью: Как долго?»: под вопросом есть кнопка «🔊 Повторить вопрос»
   - `/epoch/past-perfect/b2/station-7` — «Финальный Босс»: после выбора ответа видно полное правильное предложение и кнопку «Далее»
   - `/epoch/present-perfect/a1/station-6` — cloze «Письмо из Отпуска» (проверка старого фикса не отвалилась)
   - `/music` — промпты Suno на английском
   - `/exam` — пролог + сектора
   - **Маскот**: новый персонаж на странице эпохи и в инструктаже (файлы 1920×1920)
   - **TTS (healthcheck)**: `curl "<URL>/api/tts?text=Hello&voice=en-GB-SoniaNeural"` → 200, audio/mpeg. Если 503 — оба провайдера недоступны, проверить сеть сервера (edge-tts → фолбэк translate_tts)
   - Голосовые: бот отвечает на текст
