## 1. Что это за проект

**TELL ME PLEASE** — бесплатная интерактивная голосовая платформа для изучения английского школьниками 5-9 классов. Стек: Next.js 16 (App Router, Turbopack) фронтенд + FastAPI/WebSocket бэкенд + Kokoro TTS (Docker) + OpenCode Zen как LLM (модель `ling-3.0-flash-free` + fallback `nemotron-3-ultra-free`) + Web Speech API (STT в браузере, Chrome/Edge; текстовый фолбэк для Firefox).

**Репозиторий:** https://github.com/atrshncv-design/TELL-ME-PLEASE (ветка `main`)
**Локальный путь:** `/Users/aleksandrtrisenkov/Desktop/PROGRAMMING/РАБОЧИЕ ПРОЕКТЫ/TELL ME PLEASE`

## 2. Роли и правила

- **Пользователь (Александр)** — Functional Validator. Проверяет работу в браузере, код не пишет. Часто злится, когда модель «зависает» (долгие ответы без прогресса). **Будь краток в ответах, не explanations-простыни, действуй быстро.**
- **Модель (ты)** — Lead Engineer. Пишешь код, запускаешь, проверяешь.
- **Правило Verify:** «Verify = вывод исполнения кода, приложенный к отчёту; всё остальное — не Verify» (`Plan.md:31`). Каждый шаг = коммит + проверка.
- **Git:** все коммиты на `main` + `git push origin main`. Не трогать `Plan.md`/`todo.md` (это рабочие заметки Александра).

## 3. Методология

Используется пайплайн `mattpocock/skills` + `nick-vels/autopilot` (установлены в `.agents/skills/`, но НЕ вызываются как команды в ZCode — методология исполняется вручную по их `SKILL.md`):
1. **Grill** — один вопрос за раз, с рекомендацией, факты ищешь сам, решения пользователя. Пока не достигнуто общее понимание — НЕ кодить.
2. **Spec** — синтез в `docs/SPEC-*.md`.
3. **Tickets** — нарезка в `docs/TICKETS-*.md`, 1 тикет = 1 субагент = 1 коммит.
4. **Implement** — субагент на тикет, чистый контекст. **Важно:** параллельные субагенты на одном `main` создают гонки коммитов — используй ПОСЛЕДОВАТЕЛЬНЫЙ режим.
5. **Финал** — приёмка по критериям из spec.

**Субагенты зависают** на длинных задачах (600с таймаут). Если завис — проверь git state, возможно он успел что-то закоммитить; достань и докоммить сам.

## 5. ЧТО ОСТАЛОСЬ СДЕЛАТЬ (3 блока)

### Блок 6: Verb Bot (маскот)
**Решения grilling (Q7, Q8, Q15b):**
- Floating-компонент в углу (60-80px), на ВСЕХ экранах (главная, выбор класса, sections, внутри заданий).
- Облачко с репликами при событиях:
  - Старт задания: «Let's go!», «Scan the verb!»
  - Правильный ответ: «Great job!», «Verb power activated!»
  - Ошибка: «Try again!», «Almost!»
  - Финал задания: «Ready for the next level?»
  - Главная: «Hi! I'm Verb Bot!»
- 1 фото сейчас для всех реплик (`assets/mascot/verb-bot-original.jpg`, белый 3D-робот, синий, кнопки Past/Present/Future на груди). Архитектура: папка `frontend/public/mascot/{happy,think,cheer,sad}.jpg` → сейчас 4 копии одного файла. Клиентка пришлёт 4 эмоции позже — замена тривиальна.

**Реализация:** новый компонент `frontend/src/components/VerbBot.tsx` (floating, fixed bottom-right, z-50). Контекст `VerbBotContext` для реплик из任何 компонента (task components зовут `sayBot("Great job!")`). Показывать облачко 2-3с, потом скрыть. Реплики брать из массива по типу события (рандомно). 1 фото всегда видимо, эмоция (пока) не меняется.

**Проверка:** на главной, на sections, в задании — маскот виден, реплики появляются при ответе.

### Блок 7: Карта-миры (главный редизайн)
**Решения grilling (Q10, Q11, Q12, Q15a):**
- Заменить текущую плоскую sections-страницу (`frontend/src/app/class/[grade]/sections/page.tsx`) на карту-путь.
- **Вертикальная карта-тропа** (mobile-first, вертикальный скролл).
- **Миры-зоны по категориям** (5 миров): grammar (индиго), to-be (бирюзовый), vocabulary (изумруд), listening (янтарь), speaking (розовый).
- Каждый мир — вертикальная тропа с островками-заданиями (4-5 шт). Островок = карточка с иконкой задания + emoji + бейдж прогресса.
- Между мирами — переход + приветствие Verb Bot.
- Сверху — мини-навигация по мирам (табы/иконки для прыжка).
- Прогресс визуализирован: пройденное затемнено с галочкой, Verb Bot стоит на текущем (первом непройденном) острове.
- **Применить ко ВСЕМ 5 классам** (5,6,7,8,9) — это UX-фундамент.

**Реализация:** переписать `sections/page.tsx`. Использовать Framer Motion (`layout`, `AnimatePresence`) для анимации тропы. SVG-линия между островками (заполняется по прогрессу). Verb Bot-маркер (из Блока 6) на текущем острове. Цвета миров — из существующего `SECTION_COLOR`. Данные — из `index.json` (группировка по category уже есть в `groupExercises()`).

**Проверка:** на `/class/5/sections` — вертикальная карта с 5 мирами, островки, прогресс, Verb Bot. На mobile (chrome devtools) — вертикальный скролл работает.

### Блок 8: Геймификация
**Решения grilling (Q13):**
- **Звёзды (⭐):** за задание = балл (8/10 = 8 звёзд). Сумма в шапке карты (localStorage, расширить существующий `useProgress`).
- **Бейджи 💎:** за 100% в задании, на острове карты.
- **Звуки:** короткие эффекты на правильный/неправильный ответ + финальный фанфар. Unlock AudioContext на первом клике (autoplay policy — после user gesture работает во всех браузерах). Файлы в `frontend/public/sounds/` (найти бесплатные короткие MP3: correct.mp3, wrong.mp3, fanfare.mp3 — ~1с каждый).
- **НЕ делать:** разблокировку следующих заданий (всё открыто), streak-счётчик.

**Реализация:** расширить `useProgress` (добавить звёзды/бейджи). Новый хук `useSound` (lazy AudioContext, play файлы). Подключить в QuizTask/FillInTask/ClozeTextTask/BuildSentenceTask/DragAndDropTask (на правильный/неправильный). Звёзды в шапке карты (Блок 7).

**Проверка:** ответить правильно → звук + ⭐; ответить неправильно → звук; финал → фанфар; в шапке сумма звёзд.

## 8. Предупреждения (что НЕ делать)

- **Не запускай параллельные коммитящие субагенты на main** — гонки. Только последовательно.
- **Субагенты зависают на 600с** — если завис, проверь git, докоммить сам.
- **Не трогай `grammar_roulette.json`** — ждём слово-банк от клиентки.
- **Не конвертируй `grammar_adverbs_build.json` в cloze** без уточнения клиентки («наречие ЛИБО время» — двусмысленно, любая слово правильная).
