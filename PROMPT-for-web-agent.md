### Пошаговый план:

1. **Прочитай документацию проекта:**
   - `START.md` — точка входа
   - `DEPLOY.md` — полная инструкция по окружению (используй как референс переменных)
   - `# Architecture Specification.md` и `# Product Requirements Document (PRD).md` — что это за продукт
   - `docs/SPEC.md` — что уже реализовано (MVP 5 класса готов)

2. **Установи зависимости фронтенда:**
   ```
   cd frontend && npm install
   ```

3. **Создай `frontend/.env.local`** (для прод-деплоя z.ai — переменные бэкенда должны быть публичными HTTPS-URL; если у тебя нет URL бэкенда, используй заглушку, но оставь переменные):
   ```
   NEXT_PUBLIC_WS_URL=wss://BACKEND_URL_PLACEHOLDER/ws/chat
   NEXT_PUBLIC_API_BASE=https://BACKEND_URL_PLACEHOLDER
   ```

4. **Проверь сборку фронтенда:**
   ```
   cd frontend && npm run build
   ```
   Должно завершиться без ошибок. Все маршруты должны собраться: `/`, `/class`, `/class/[grade]/sections`, `/class/[grade]/sections/[section]/[taskId]`.

5. **Проверь типы:**
   ```
   cd frontend && npx tsc --noEmit
   ```
   Должно быть 0 ошибок.

6. **Если в репозитории есть backend — НЕ пытайся его запускать здесь** (FastAPI + WebSocket требуют отдельного хоста и Docker для Kokoro). Просто удостоверься, что код на месте, и оставь для отдельного деплоя бэкенда.

7. **Проверь контент:**
   ```
   node scripts/verify-content.mjs
   ```

9. **По завершении** — кратко отчитайся: что собрано, что проверено, какие переменные окружения нужны для деплоя (особенно `NEXT_PUBLIC_WS_URL` и `NEXT_PUBLIC_API_BASE`), и подтверди готовность к нажатию кнопки Deploy.

### Важные ограничения проекта (НЕ нарушать):

- **Запрещён server-side STT** (Whisper на бэкенде) — только Web Speech API в браузере.
- **Запрещена динамическая генерация промптов LLM** — все промпты hardcoded в `backend/app/prompts_config.json` по `branch_id`/`task_id`.
- **Запрещена утечка API-ключей** на фронтенд — все запросы к LLM проксируются через FastAPI.
- **Обязателен streaming pipeline** — токены LLM → sentence buffer → Kokoro TTS → WebSocket → AudioContext на клиенте.
- **Пароли и ключи — только в `.env`** (gitignored), никогда в коде.

### Контекст для развёртывания:

Главный бэкенд-процесс — это FastAPI на порту 8000 (WebSocket `/ws/chat`, HTTP `/api/event`, `/admin/status`). Kokoro TTS — Docker на порту 8880. Фронтенд — Next.js на порту 3000. Для продакшена нужно: фронт задеплоить здесь (через кнопку Deploy), бэкенд+Kokoro — на отдельном хосте (Render/Railway/Fly.io), и прописать их URL в `frontend/.env.local` как `NEXT_PUBLIC_WS_URL` (wss://) и `NEXT_PUBLIC_API_BASE` (https://).
