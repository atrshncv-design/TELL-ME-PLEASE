# Спецификация: финальные штрихи правок

## Задача

Ученик должен получать исправный, понятный и соответствующий материалам клиентки
тренажер: теория читается без лишних строк, задания не показывают готовые ответы,
непустые станции остаются доступными, а переход к Великому экзамену работает.

## Решение

Обновить обозначенные данные эпох и их served-зеркала, точечно исправить общий UI
для мгновенной обратной связи и доступности следующего вопроса, а также снять
регистрацию только у действительно пустых станций. Внешние сервисы, API и новые
зависимости не затрагиваются.

## Решения по реализации

- Источник контента - `content/epochs`; каждое изменение JSON повторяется байт-в-байт в `frontend/public/content/epochs`.
- Новая A1 Present Simple станция фильтра получает новый идентификатор и регистрируется второй, без переиспользования существующих `station-2` и `station-2-b`; это сохраняет старый прогресс и прямые ссылки.
- Пустые станции R22, R24 и R25 исключаются только из соответствующих `index.json`; физические JSON-файлы не удаляются.
- R26 отменено пользователем: B2 Future Simple station-8 сохраняется, форматирование реплик выполняется именами в `**жирном**` виде.
- Мгновенная цветовая обратная связь должна оставаться единой для `QuizTask`; если поведение уже реализовано, тикет ограничивается регрессионной проверкой, без дублирующего кода.
- Видимость «Следующий вопрос» исправляется в общем UI voice-chat: управляющая кнопка не должна теряться за прокруткой или фиксированным Verb Bot.
- FPC voice-chat сохраняет существующий формат диалога и микрофон; исправляется только повтор вопроса внутри блока подсказки.
- Доступ к экзамену не зависит от наличия учебного прогресса в `localStorage`; страница `/exam` остается обычным маршрутом приложения.
- Никаких изменений в `frontend/src/server/**`, `/api/**`, `.zscripts/`, поставщиках TTS/LLM или зависимостях.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| Epoch JSON и index | тексты, задания, порядок станций | контракт текущего `TaskRenderer` | внутренние формулировки и варианты |
| `EpochTheory` | CTA, слайды теории и названия песен | рендер теории из `index.json` | разбиение слайдов |
| `QuizTask` | выбор, вердикт и задержку перехода | единый UI quiz | CSS-состояние верного/неверного выбора |
| `VoiceChatTask` | вопрос, подсказку, вердикт и навигацию | отображение конкретной voice-chat станции | раскладку скролла и позиции управляющих кнопок |
| `ExamEntryCard` | переход пользователя к экзамену | ссылка на `/exam` | детали локальной проверки прогресса |

Швы для проверки: JSON-валидаторы и побайтное сравнение зеркал; `QuizTask` для мгновенного вердикта; `VoiceChatTask` для видимой кнопки; `ExamEntryCard` для активной ссылки.

## Вне рамок

| Требование | Почему не сейчас |

| R26 | Пользователь отменил удаление B2-диалога: «Оставить диалог» |

| R17, R23, R28 | Данные уже соответствуют документу; требуется доказать отсутствие регрессии, не переписывать их |
