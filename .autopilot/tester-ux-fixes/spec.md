# Спецификация: Правки UX по обратной связи тестировщика

## Задача

Тестировщик (взрослый пользователь с телефона) впервые прошла платформу и наткнулась на шесть шероховатостей: робот-помощник выглядит живым, но на нём нельзя нажать — а она ожидала диалога с ним; его иконка наезжает на текст; длинное название станции ломает кнопку «← Назад» в шапке; выключатель звука не глушит голос бота; при неверном ответе зелёная галочка появляется у ПРАВИЛЬНОГО варианта, и кажется, что ответила правильно; на экране обучения кнопка звука прячет собой другую кнопку. «А так, мне понравилось 🔥»

## Решение

Verb Bot становится живым собеседником: клик по нему открывает знакомый по голосовым заданиям чат, где собеседник — сам Verb Bot. Контент больше не заезжает под бота. Шапка станции держит длинные названия. Выключатель звука глушит вообще весь голос платформы. Неверный ответ невозможно принять за верный. На экране обучения ничего не спрятано под кнопкой звука.

## Решения по реализации

- **R01**: переиспользуем существующий движок голосовых чатов (`VoiceChatTask`-паттерн: `useSpeechSynthesis` + server TTS фолбэк + STT) в новой модалке `BotChat`, вызываемой из `VerbBot`. Персона бота — системный промпт «Verb Bot, дружелюбный репетитор английского». LLM — существующий SSE `/api/chat/stream` (branch_id свободного чата). Почему так: механика уже обкатана детьми, новая — риск и время.
- **R04**: глушилка читает один ключ `SOUND_STORAGE_KEY`; проверка ставится ЦЕНТРАЛЬНО в оба речевых канала (browser TTS `speak()` и server-TTS хук), плюс немедленный `stop()` активной речи при выключении. Почему так: точечные проверки в каждом таске гарантированно где-то забудут.
- **R05**: единый хелпер стилей вердикта для instant-check компонентов (QuizTask первым, остальными — по факту наличия того же паттерна); константы таймингов в одном месте. Почему так: паттерн повторяется, расхождения между заданиями и раздражают.
- **R06**: пока открыта полноэкранная модалка обучения, глобальный `SoundToggle` скрывается, а в шапке модалки рядом с «✕» появляется собственный компактный тумблер. Почему так: убирает коллизию полностью и отвечает на «что там торчит» — вторая кнопка становится видимой и осмысленной.
- **R02**: резерв места — нижний паддинг контентного контейнера на мобильных там, где флоат-бот активен; пузырь речи скрывается при скролле и позиционируется так, чтобы не накрывать интерактив. Почему так: гарантированно убирает «заплывает на текст» без изменения дизайна бота.
- **R03**: чисто CSS-фикс `TaskHeader` (`shrink-0 whitespace-nowrap` кнопке, `min-w-0` заголовку). Без изменения структуры.
- **R01×R04 (поправка после ревью тикета 01)**: при выключенном звуке чат с ботом продолжает работать — реплики бота видны текстом, сообщение «не получилось озвучить» НЕ показывается (mute — не ошибка сети). Код доказал пересечение требований на тикете 01 (D01).
- **R02 (уточнение после ревью тикета 01)**: резерв места обязателен и на полноэкранных страницах заданий (жалоба тестировщицы снята именно там); способ — на усмотрение исполнителя, но раскладка dvh ломаться не должна.
- Стек не меняется. Next.js в этом репо отличается от привычной документации (см. frontend/AGENTS.md) — исполнителям читать локальные доки перед кодом.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `VerbBot` + `BotChatModal` | флоат-бот, окно голосового чата | клик по аватару → модалка; пропсы позиции | выбор ветки speech/STT, персону промпта |
| `speech gate` (useSound-ключ) | правило «глушит ли звук всё» | `isSpeechAllowed(): boolean` + вызов в обоих speak-каналах | чтение localStorage |
| `verdict style helper` | визуал вердикта instant-check | константы классов и таймингов | логику таймеров конкретных тасков |
| `TaskHeader` | шапка станции | пропсы title/backHref (без изменений) | раскладку |
| `EpochTheory × SoundToggle` | видимость тумблера | флаг «модалка обучения открыта» | координацию z-слоёв |

Шов для проверок один: поведение через публичные поверхности компонентов (клик, тумблер, выбор варианта). Автотестов в репо нет — приёмка через tsc/build + ручной сценарий из историй.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Пуш/деплой на прод | наружное действие — только по явному «ок» пользователя после приёмки |
| Переделка дизайна бота (новые эмоции/анимации) | R02 требует лишь убрать наложение; внешний вид не жаловался |
| Контекстные подсказки бота про текущее задание | выбран свободный голосовой чат с Verb Bot (G01); контекстность — отдельная большая история |
