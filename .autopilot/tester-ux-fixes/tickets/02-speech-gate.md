# 02 — Звук: единый речевой гейт

**Blocked by:** —

**Status:** ready

## Что должно заработать

Выключатель звука глушит ВСЁ: и звуковые эффекты (уже работает), и озвучивание речи ботом — как браузерное, так и серверное. Выключение действует немедленно: что уже говорилось — замолкает. Включение возвращает речь без перезагрузки страницы.

## Из брифа, дословно

> «даже если я выключаю звук, то он не все равно произносит речь. А: Должно быть такое, что если я звук выключила, то я ничего не слышу. У меня никто не произносит, никакие предложения, не читает»

## Разделы спецификации

Истории 8–9, Решения §R04, Границы §speech gate.

## Критерии приёмки

- [ ] Проверка `isSpeechAllowed()` стоит ЦЕНТРАЛЬНО в обоих каналах речи (browser TTS `speak()` и server TTS), а не в каждом таске
- [ ] При выключенном звуке ни один канал не воспроизводит речь (проверить оба провайдера)
- [ ] Выключение во время звучащей фразы останавливает её сразу
- [ ] Повторное включение возвращает речь без перезагрузки страницы
- [ ] Звуковые эффекты (correct/wrong/fanfare) продолжают управляться тем же тумблером, регрессии нет
- [ ] `npx tsc --noEmit` и `npm run build` зелёные
