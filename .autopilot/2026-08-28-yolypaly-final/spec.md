# Спецификация: Финал ЁЛЫПАЛЫ — повторные правки

## Задача

Клиентка видит, что часть предыдущих правок либо загромождает экран (таблица 28 глаголов), либо не доехала (мини-проект, перевод-ловушка), а Великий экзамен не находится. Нужно привести задания к финальному виду без потери полезного контента и сделать экзамен логическим финалом карты.

## Решение

Точечно исправить указанные JSON и UI: убрать постоянно видимую таблицу неправильных глаголов, показывать формы только после проверки; вынести фильтр и экзамен туда, где их ждут; оставить по одному экземпляру из задвоенных промптов; привести маркеры BY/AT к проверке без подсказок в опциях. Зеркала остаются byte-identical, сервер/API не трогаются.

## Решения по реализации

- Источник — `content/epochs` + зеркало `frontend/public/content/epochs` (byte-identical).
- Удаление «огромного списка» — из `past-simple/a1/station-0.json` (или ранее расширенного) удалить статичную таблицу; вывод трёх форм перенести в рендер результата проверки выбранного item.
- `Viktorina Vremen` — исправить `past-simple/a2/station-?` (фактически `past-simple/a2/station-3` или аналогичный quiz) на `Have you tried sushi before?`.
- Recorder — заменить готовые формы в `present-perfect/b1/station-4.json` на `___` + `word_bank` из начальных форм (11 слов из документа); 7-й answer — `showed`.
- Problem/Result — `present-perfect/b1/station-5.json` item7: `answer: ["have spilled","have spilt"]` уже, но проверить что оба зелёные (было красным).
- Дубли: в `present-perfect-continuous/index.json` и `future-simple/index.json` оставить по одной регистрации из каждой пары задвоенных `station-8/9`; файлы не удалять. Подтверждено «Оставить одну».
- BY/AT — в `future-perfect/a1/station-3.json` убрать `by`/`at` из `options`/`word_bank`, оставить `5 p.m.` и т.д.; `answer` остаётся в корзинах.
- Great Exam — в `frontend/src/app/mission/page.tsx` ниже карты добавить секцию `Великий экзамен` с `ExamEntryCard` (всегда активна), в `epoch/[slug]/page.tsx` (FPC) оставить подсказку.
- Snake/Crazy Day/Conditionals — отдельные `exam` секторы: `exam/present` `my-crazy-day`, `exam/past` `snake-rabbit`, `exam/future` `conditional-trap` + `space-mission` — скорректировать `content/exam` JSON по ключам из документа.
- Нет изменений в `frontend/src/server/**`, `/api/**`, `.zscripts/`, зависимостях.
