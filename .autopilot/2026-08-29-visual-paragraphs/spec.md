# Спецификация: визуально красивое обучение и правки 290826

## Задача

Ученик открывает «Обучение» и видит плотный текст без пауз: подзаголовки 2 и 3 прилипают к предыдущему предложению, нумерация 1./2. склеивается. Нужен воздух между блоками, чтобы читать не уставать. Параллельно клиентка уточнила финальные тексты и механику нескольких станций.

## Решение

Вынести теорию в визуально разделённый вид: системные отступы между абзацами, каждый нумерованный пункт — отдельной карточкой/строкой, заголовки этапов — с разделителями. Точечно обновить указанные станции и тексты, зеркала — byte-identical, сервер не трогаем.

## Решения по реализации

- Источник — `content/epochs/*/index.json` (theory) + `content/exam/` + зеркала `frontend/public/content/...` byte-identical.
- Визуал: в `EpochTheory` рендерить `text` с учётом `\n\n` → `<p>` с `mb-4/6`, нумерованные `1.`–`7.` — парсить в `TheoryList` карточками `bg-amber-50 border` как уже для TO BE, но системно для всех `Шаг 2`/`Шаг 3`. Заголовки `Шаг 2:`/`Шаг 3:` — `h3` с `mt-6 mb-2 font-bold`. Выбранный в брифинге «Да, системно».
- `hasWordAudio`, `EpochTheory` слайды — типографика без изменения смысла, только whitespace.
- Past Simple huge list — удалить `description` таблицу из `past-simple/a1/station-0.json`, `explanation` оставить для пост-проверки (как в yolypaly).
- `noon` — в `future-perfect/a1/station-3.json` сделать `items` с `id` (`noon-1`, `noon-2`, `noon-3`) и `verb:"noon"` + `answer` BY/AT, чтобы `DragAndDropTask` использовал `id` как key, а не `verb`. Зона `frontend/src/components/tasks/DragAndDropTask.tsx` — заменить key `verb` → `id` (поддержан предыдущим тикетом как `verb` + fallback, но теперь явно).
- Стрелки — в `QuizTask`, `ClozeTextTask`, `FlashcardsTask` добавить `prev/next` с `current` state, без `onComplete` до «Проверить». «Да, во всех».
- Футер — `frontend/src/components/RightsFooter.tsx` — два `<p>` в новом порядке, телефон `+7 929 275 10 54`.
- Translation 6+ `have` — в `present-perfect/b1/station-3.json` answers 6–10 с `have/has ...` (finish → `have already finished` и т.д.).
- `R15` Mini-проект, `R16` guitar, `R17` Great Exam/дубли/интеграция — уже выполнены в прогоне `yolypaly-final` (проверка регрессии, без новых правок).
- Нет изменений в `frontend/src/server/**`, `/api/**`, `.zscripts/`, зависимостях.
