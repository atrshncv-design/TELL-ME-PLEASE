# 01 — Плакат-ассет, метаданные эпох, компонент карты

## Что должно заработать

Оптимизированный ассет плаката и компонент `EpochMapPoster`, который рисует плакат
с живыми компактными карточками в ячейках (иконка + название + тэглайн + кнопка
«Войти →»), галочкой на полностью пройденной эпохе и фолбэком при незагрузке ассета.
Метаданные эпох вынесены из `app/mission/page.tsx` в `lib/epochs-meta.ts`.

## Из брифа, дословно

> «У клиентки есть файл с основой карты - туда просто в пустые ячейки вставим текущие карточки эпох и они органично встанут»
> «в ячейки будем вставлять карточки эпох с кнопками»
> «Галочка на пройденной эпохе» — «Галочка = вся эпоха (все 4 сектора)»
> «Компакт: иконка+название+кнопка»

## Разделы спецификации

Истории 1–5, 10, 12; Решения 1–5.

## Критерии приёмки

- [ ] `frontend/public/map/epoch-map.svg` ≤ 700KB, визуально = исходник (фон, робот, спутник, таблица)
- [ ] `EPOCH_META` содержит все 12 эпох со slug/number/title/tagline/icon и ячейкой матрицы (строка Present/Past/Future × колонка Simple/Continuous/Perfect/PerfectContinuous — раскладка по грамматике, НЕ по номеру изучения)
- [ ] Ячейки позиционируются долями viewBox (3401.57×1700.79): x₀≈301.8, шаг колонки ≈739.3, y₀≈254.7, шаг строки ≈460.65, ячейка ≈718.5×438.3 — выравнивание держится на любой ширине
- [ ] Карточка в ячейке: иконка, название, тэглайн, кнопка «Войти →» (`/epoch/<slug>`), кликабельна, min-height 44px, фокус с клавиатуры
- [ ] Галочка на ячейке только когда все 4 сектора эпохи пройдены (прогресс — через существующие функции `lib/epoch.ts`)
- [ ] onError/отсутствие ассета → компонент сигнализирует фолбэк (проп/колбэк), не падает
- [ ] `npx tsc --noEmit` = 0, `npm run build` успешен
- [ ] Компонент НЕ подключён ни к одной странице в этом таске (это T02); страницы не меняются
