# 03 — Вход на Великий Экзамен со страницы последнего времени (FPC)

**Требования:** G03, G03.1
**Blocked by:** —
**Зона:** `frontend/src/app/epoch/[slug]/page.tsx`, `frontend/src/lib/epoch.ts` (только чтение/переиспользование, без изменений API)
**Волна:** 1
**Status:** ready

## Что должно заработать

На странице эпохи `future-perfect-continuous` появляется карточка «Великий Экзамен
Времен» внизу списка секторов. Пока не пройдены все 4 сектора FPC — карточка серая
с подсказкой «Сначала пройди Future Perfect Continuous», клик ничего не делает.
Когда все 4 сектора пройдены — активная, ведёт на `/exam`. На остальных эпохах
ничего не появляется.

## Из брифа, дословно

> «Великому экзамену можно перейти после выполнения последнего времени - прямо оттуда, а не из общей карты 12 времён»
> «Карточка на странице FPC, открывается после прохождения»
> «Галочка = вся эпоха (все 4 сектора)» — тот же порог для экзамена

## Разделы спецификации

Истории 8–9; Решение 6.

## Критерии приёмки

- [ ] Карточка есть только на `/epoch/future-perfect-continuous`
- [ ] Неактивное состояние: `opacity-60`, подсказка, без перехода; активное: переход на `/exam`
- [ ] Порог: все 4 сектора FPC пройдены (через существующие функции прогресса, без новых хранилищ)
- [ ] Остальные 11 эпох визуально не изменились
- [ ] Дизайн карточки — в стиле текущей янтарной карточки экзамена (которая уходит с /mission): можно переиспользовать её разметку
- [ ] `npx tsc --noEmit` = 0, `npm run build` успешен
