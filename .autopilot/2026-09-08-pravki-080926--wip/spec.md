# Спецификация: Правки 080926 — маркеры, кнопка сектора, фильтр

## Задача

Клиентка смотрит сборку глазами ученика: термин «слова-шпионы» режет слух —
просит «слова-маркеры»; пройдя сектор до конца, приходится выходить назад,
чтобы попасть в следующий; зелёная кнопка (бейдж пройденного) непонятна;
упражнение в Present Simple A1 получает цепляющее название и точную
формулировку правила; по анкетам просит сказать, что добавить.

## Решение

Когда готово: везде, где был термин «слова-шпионы», — «слова-маркеры»; в конце
каждого сектора — кнопка перехода в следующий сектор (с последнего — к карте
эпохи), синяя, как вся навигация; зелёный цвет остаётся языком «пройдено», что
объясняем клиентке; станция фильтра — с новым названием и новым текстом
правила; клиентке уходит готовый список правок анкет для Word.

## Решения по реализации

Термин — это данные: замена строкой по всем JSON контента и кода, механика не
трогается; почему так: термин ни на что не влияет, кроме текста.

Кнопка сектора — на существующем шве возврата/перехода: следующий сектор из
индекса эпохи, край — карта эпохи; синий стиль навигации; почему так: зелёный
уже занят семантикой «пройдено».

Фильтр — два поля одного файла + index, оба зеркала; скобка в названии —
дословно как у клиентки; почему так: название — её слова.

Анкеты — только текстовый список (Word-файлы клиентки недоступны для правки);
почему так: ответ 08.09 «отправить список».

Проверки: типы 0 ошибок, сборка зелёная, валидаторы ALL PASSED, зеркала
идентичны.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| Страница сектора | список станций, кнопка «К следующему» | следующий sector.id из индекса эпохи | роутинг |
| Контент эпох/заданий | термины и тексты в двух зеркалах | JSON-файлы | ничего — данные |

Швы для тестов: те же (валидаторы, типы, сборка, diff зеркал). Новых нет.
НЕ ТРОГАТЬ: достижения, печать, экзамен, server/api, .zscripts, PDF.
